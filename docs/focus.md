# 专注计时与休息提醒

在 MoonPet 设置中展开「专注计时」。默认工作 25 分钟、休息 5 分钟，可在未计时状态调整为 1–180 分钟。

- 开始工作：启动倒计时并记录工作时长。
- 暂停／继续：暂停的时间不计入工作。
- 结束：结束当前计时，保留已经工作的时间。
- 工作到期：记录完整这一轮，响铃并显示休息提示；点击「开始休息」后启动休息计时。休息不计入工作时长。
- 休息到期：MoonPet 对话框显示休息结束提示和「开始专注」按钮，点击后按当前已保存的工作时长开始下一轮，并停止响铃；不自动启动下一轮。提醒卡片也提供相同入口。
- 试听：播放约 3 秒。停止提醒可立即结束声音并关闭提醒卡片。

在「专注陪伴」中选择按时间间隔鼓励（1–60 分钟，默认 5 分钟）、按进度鼓励（25%／50%／75%），或关闭主动陪伴语。设置即时保存，重启后保留，运行中修改不重置倒计时；切换方式不会补播已错过的提醒。关闭陪伴语仍保留到期提醒卡片和响铃。

专注过程中，角色通过原有对话框显示「您已专注 X 分钟」和鼓励语，默认静音，不调用模型。台词结合专注前半程、过半、最后一段和任务状态变化，同一情境下轮换表达。按本轮实际工作时间计算，暂停时间与休息时间不计入；恢复时继续计算，新一轮重新开始。较晚收到计时状态时只显示当前进度，不补播错过的提示。

开始、暂停、继续、工作完成和休息切换也提供简短陪伴语。窗口隐藏、设置面板打开、角色或对话框关闭、已有台词或账单正在展示、任务等待审批时跳过自动陪伴语，不排队补播。到期提醒卡片和响铃继续照常工作。

休息结束的下一轮入口不受「关闭主动陪伴语」影响，也不会自动消失。如果当前不适合显示对话框，待窗口恢复可见、设置关闭、已有内容结束或审批等待解除后再显示；点击「停止提醒」可关闭该入口。关闭角色或对话框时仍可通过提醒卡片或设置面板开始专注。

今日与累计工作时间保存在 `~/.dsh/.dsh-moonpet-focus.json`，使用 Asia/Shanghai 日期统计。工作记录每 30 秒落盘，暂停、结束、到期和正常退出时也保存。窗口隐藏不暂停，完全退出应用会暂停；异常关闭后恢复为暂停，不补算应用关闭期间的时长。

## 提醒音

现提供十一种提醒音：清脆颂钵、柔和双音、空灵八音盒、云朵竖琴、竹林水滴、温暖电钢、轻柔脉冲、语音温柔提醒、轻柔和弦、电子脉冲、三音铃声。保留远程更新提供的八种声音，并补充三种本地数学合成音效。

运行或暂停计时期间也可修改提醒音，保存后用于后续提醒；倒计时与工作记录保持不变。时长仍需结束计时后修改。使用「试听 3 秒」预听所选声音；正在播放的声音可点击「停止提醒」终止。正式提醒最长 20 秒。

试听和到期提示音均跟随 MoonPet 的「音量」滑块，0% 静音；播放期间调整也会生效（Windows 后端在设置保存后更新）。此设置只调整 MoonPet 播放音量，不更改系统或其他应用的音量；实际响度仍受系统音量影响。

Windows 后端使用独立、隐藏的 WPF MediaPlayer 音频助手播放，支持单独音量与循环提醒。详细来源、逐项许可和 SHA-256 见 `assets/alerts/sources.json`；三种补充音效可用 `python scripts/generate-focus-tones.py` 重新生成。

其他平台通过浏览器播放声音，可能受到浏览器自动播放政策限制；Windows 本地后端播放不依赖浏览器自动播放。无需模型调用或运行时联网。

## 验证与启动

计时引擎通过假时钟测试，覆盖到期只结算一次、暂停恢复、休息不计入工作、跨日统计、关闭恢复与损坏记录。浏览器测试验证开始、暂停、到期、开始休息、三秒试听及立即停止。

新增后端需要完全退出并重新打开 Harness 才能加载，仅刷新页面不足以加载后端。不要在正在运行重要任务时强制关闭应用。
