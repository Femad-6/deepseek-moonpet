# v0.1.5（GitHub Release，2026-10-24）

- 新增樱铃、星璃、森柚三套角色，每套八张透明状态立绘。
- 激励台词由 12 句扩充为 25 句，保留完整中／英／日字幕。
- 独立语音包包括两种中文女声、两种中文男声和美式／英式英文女声，每套 25 句，共 150 段音频。
- 四套中文按试听反馈使用 Qwen3-TTS 1.7B 重录为轻柔陪伴版；两套英文保持 Kokoro 原版。
- 延续鲸蓝头像、冰蓝设置面板、十一种提醒音以及番茄钟运行时切换提醒音的修复。

在 [v0.1.5 Release](https://github.com/Femad-6/deepseek-moonpet/releases/tag/v0.1.5) 下载 `dsh-moonpet-0.1.5.tgz`，在 Harness 插件安装入口填写安装包链接或本地绝对路径，启用后完全退出并重启 Harness。本次仅发布 GitHub，未发布 npm。

另下载 `moonpet-natural-voices-25-lines-20261024.zip`，解压后把六个包目录复制到 `~/.dsh/dsh-moonpet/packs/`，刷新页面后在「字幕与资源 → 语音包」选择。模型权重和生成环境不随插件或语音包分发；播放无需联网或模型推理。

附件校验见 `SHA256SUMS-v0.1.5.txt`，语音包内含每段音频的 `generation.json` 来源与哈希记录。已验证 43 项离线测试、打包收录和浏览器切换／播放；主观听感仍以试听为准。

# v0.1.0

MoonPet（月伴）是 DeepSeek Harness 的社区状态宠物与专注计时插件，基于 dsh-gal 的 MIT 代码扩展，保留原作者署名。

本版提供：

- 根据真实 Harness 会话事件切换待机、思考、工具执行、等待审批、完成和异常状态。
- 三张 AI 辅助生成的默认立绘，CSS 轻微动作与简洁设置面板。
- 默认 25 分钟工作／5 分钟休息的手动番茄钟，暂停恢复、今日和累计工作记录。
- 三种已下载的 CC0 提醒音；Windows 后台播放，试听与停止控制。
- 中／英／日字幕，可选中文与英文励志语音包，各 12 条。

下载 `dsh-moonpet-0.1.0.tgz`，在 Harness 的插件页面输入本地绝对路径或安装包 URL，安装并启用，然后完全退出再打开应用。

`moonpet-multilingual-voices.zip` 是可选语音资源，不是插件安装包。解压后将两种语音包目录复制到 `~/.dsh/dsh-moonpet/packs/`，刷新页面再选择。

`SHA256SUMS.txt` 用于核对附件完整性。

尚未发布 npm。自动测试不调用模型；Windows 声音仍受系统音量与静音影响。其他平台的提醒音依赖浏览器自动播放权限。仅计时人工开启的专注区间，不检测真实键盘活动。
