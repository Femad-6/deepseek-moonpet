# Asset provenance

`packs/sakura/sprites/*.png`, `packs/stella/sprites/*.png`, and `packs/yuzu/sprites/*.png` were generated on 2026-10-24 using the built-in ImageGen tool from original text descriptions approved by the project user. Each character was generated as a 1536x1024 transparent 4-by-2 sheet, then mechanically split into eight 384x512 RGBA PNGs using System.Drawing; the generated alpha channel is preserved. No game assets, external character references or voices were copied. The shared prompt, character-specific prompts, and state order are recorded in `docs/characters.md`. The rights limitations below apply to these generated assets as well.

`icon.svg` is a self-contained SVG portrait tile embedding the bundled `packs/whale/sprites/idle.png` illustration, framed and cropped with code-authored SVG geometry. Its embedded bitmap is encoded as lossless WebP using Pillow (`lossless=True`, `method=6`, `exact=True`), preserving the original canvas dimensions and all visible source pixels; rows below the SVG clipping area are cleared with an interpolation guard while keeping the complete SVG below DSH's 256 KiB plugin-icon limit. The original PNG sprite is unchanged. It shares that illustration's provenance and rights limitations below. The settings panel uses the same portrait through `/dsh-moonpet/asset/ui/brand.svg`; no external image service is required.

`packs/whale/sprites/*.png` contains eight state illustrations generated on 2026-10-07 with the built-in ImageGen tool from a user-provided blue-haired ocean maid reference and the full-body illustration generated in this conversation. A generated 4-by-2 sprite sheet was mechanically separated into equal cells; the reference itself is not distributed. Character: 鲸蓝 · Whale. Prompt: preserve blue/cyan hair, whale clip and plush, blue-white frilled maid dress; full-body consistent-scale transparent sprites for gentle idle, thoughtful thinking, focused working, expectant raised-hand waiting, joyful victory done, worried error, calm stopped and sleepy offline. No upstream game assets or character voices were copied. Generated assets carry the same rights limitations described below.

`packs/moon/sprites/idle.png`, `thinking.png`, and `wave.png` were AI-assisted generations made for this project, using a visual reference supplied by the project user. They are not extracted files from the upstream demo pack; the reference itself is not included. No claim is made that generated output has exclusive copyright or that reference material is owned by this project.

`ui/dialog.png`, `dialog-blank.png`, `settings.png`, and `click.wav` were programmatically generated for MoonPet. They contain geometric UI shapes and a synthesized brief tone, not sampled game art or audio.

Contributors grant permission to use, modify and redistribute the new assets under the repository MIT terms to the extent of rights they hold. Third-party rights, if any, are not transferred by this statement. Users should supply assets they are entitled to use when creating their own packs.

The built-in pricing JSON is an inherited historical snapshot used only for estimated cost display. It is not a current price guarantee.

`alerts/bells.wav`, `chime.wav`, `wind.wav`, `harp.wav`, `water.wav`, `piano.wav`, and `pulse.wav` are the procedurally synthesized tones supplied by upstream commit 777adee; `voice.wav` combines a chime with MeloTTS speech. Their source descriptions, individual licenses and SHA-256 hashes are preserved in `alerts/sources.json`.

`alerts/soft.wav`, `digital.wav`, and `triple.wav` are original mathematically synthesized tones generated by `scripts/generate-focus-tones.py` (mono 22050 Hz 16-bit PCM, envelope fades and peak limiting). They are distributed under the repository MIT terms; no external recordings are sampled.

## Hand-drawn dialogue balloon

`ui/dialog-handdrawn.svg` is an original vector drawing for MoonPet, visually inspired by the irregular oval and integrated tail of [手書きお団子ふきだし1](https://fukidesign.com/e1846/) by TopeconHeroes / ダーヤマ. The downloaded reference SVG is not included in the package; the path was drawn anew for this widget.
