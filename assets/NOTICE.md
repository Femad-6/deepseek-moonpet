# Asset provenance

`icon.svg` is a self-contained SVG portrait tile embedding the bundled `packs/whale/sprites/idle.png` illustration, framed and cropped with code-authored SVG geometry. It shares that illustration's provenance and rights limitations below. The settings panel uses the same portrait through `/dsh-moonpet/asset/ui/brand.svg`; no external image service is required.

`packs/whale/sprites/*.png` contains eight state illustrations generated on 2026-10-07 with the built-in ImageGen tool from a user-provided blue-haired ocean maid reference and the full-body illustration generated in this conversation. A generated 4-by-2 sprite sheet was mechanically separated into equal cells; the reference itself is not distributed. Character: 鲸蓝 · Whale. Prompt: preserve blue/cyan hair, whale clip and plush, blue-white frilled maid dress; full-body consistent-scale transparent sprites for gentle idle, thoughtful thinking, focused working, expectant raised-hand waiting, joyful victory done, worried error, calm stopped and sleepy offline. No upstream game assets or character voices were copied. Generated assets carry the same rights limitations described below.

`packs/moon/sprites/idle.png`, `thinking.png`, and `wave.png` were AI-assisted generations made for this project, using a visual reference supplied by the project user. They are not extracted files from the upstream demo pack; the reference itself is not included. No claim is made that generated output has exclusive copyright or that reference material is owned by this project.

`ui/dialog.png`, `dialog-blank.png`, `settings.png`, and `click.wav` were programmatically generated for MoonPet. They contain geometric UI shapes and a synthesized brief tone, not sampled game art or audio.

Contributors grant permission to use, modify and redistribute the new assets under the repository MIT terms to the extent of rights they hold. Third-party rights, if any, are not transferred by this statement. Users should supply assets they are entitled to use when creating their own packs.

The built-in pricing JSON is an inherited historical snapshot used only for estimated cost display. It is not a current price guarantee.

`alerts/bells.wav`, `chime.wav` and `wind.wav` are excerpts/transcodes of CC0 audio downloaded from Wikimedia Commons. They retain their source CC0 status rather than being relicensed as exclusive project assets. Authors, source URLs, transformation details and hashes are in `alerts/sources.json` and `docs/focus.md`.

`alerts/soft.wav`, `pulse.wav`, and `triple.wav` are original mathematically synthesized tones generated by `scripts/generate-focus-tones.py` (mono 22050 Hz 16-bit PCM, envelope fades and peak limiting). They are distributed under the repository MIT terms; no external recordings are sampled.
